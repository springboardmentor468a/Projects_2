# AI Vision Extract

This project was developed as part of the **Infosys Springboard Internship**.
The goal of this project is to build an AI system that can detect the main subject in an image and generate segmentation masks using deep learning.

# Tasks :
**Task 1 – Dataset Preparation**
* Used COCO dataset for image segmentation
* Collected images and corresponding masks
* Organized dataset for training

**Task 2 – Data Preprocessing**
* Resized images to 128 × 128
* Normalized pixel values
* Prepared data for model training

**Task 3 – Binary Mask Conversion**
* Converted masks into binary format
* Background = 0
* Foreground object = 1

**Task 4 – Model Training**
* Built a U-Net based segmentation model
* Framework used: Keras / TensorFlow
* Generated trained model file: **unet_task4_final.h5**

**Task 5 – Deployment**
* Developed a Streamlit web application
* User uploads an image
* Model predicts segmentation mask
* Displays isolated foreground output
